# O repositório é a fonte da verdade; o Lichess é a nascente

Coletamos cada Torneio Válido uma vez e arquivamos sua Classificação e seus PGN neste repositório; rankings, Recortes e a página publicada são todos derivados desse arquivo versionado.

O Lichess não garante retenção de torneios antigos e já mudou nomes e formatos ao longo da história do grupo. Como esta base vira histórico de temporadas e decisão de pódio, depender de uma API que pode sumir é dívida. Efeito colateral deliberado: a coleta pode falhar sem derrubar a página, e toda correção de resultado fica visível no git.
